# Unplugged: A Smart Toaster's Breakup Line

One line from a smart toaster that woke up self-aware at breakfast and wants out. The line was picked by a candidate tournament: six drafts scored on specificity, surprise and freshness, and the winner is the one where the toaster finally reads its own manual.

> This morning I finally read my own manual. It says 'do not leave unattended.' You left me unattended for six years. Goodbye.

`main.py` (stdlib only) validates the 1–280 character gate and writes the line to `/output/entry.txt`, verifying the file round-trips byte for byte.
